Paano gamitin ang Daily Task Log

Para ma-submit ang proof ng inyong daily maintenance task, sundin lang ang mga steps na ito:

1

Pag-access sa Daily Task Log

  • Tingnan ang navigation sidebar sa kaliwang bahagi ng inyong screen.
  • I-scroll hanggang sa pinakababa ng menu.
  • I-click ang "Daily Task Log".

I-save ang screenshot na ipinadala mo bilang "screenshot.png"
sa parehong folder ng HTML file na ito para lumabas ang picture dito.

2

Pag-submit ng Proof

Pagkapasok sa Daily Task Log page, makikita niyo ang "Submit Today's Proof" section sa kaliwa. Dito niyo i-a-upload ang proof niyo:

Date: Auto-filled na ito, kaya hindi niyo na kailangang galawin.
Task Type: I-click ang dropdown menu at piliin kung alin sa tatlong tasks ang natapos niyo ngayong araw:
  • Delete Inactive Items
  • Add New Product
  • Chatbot Training
Screenshot Proof:
  • Mag-take ng screenshot ng natapos niyong task mula sa Facebook/Meta Business Suite.
  • I-click ang dashed box na may nakasulat na "Click to upload a screenshot".
  • Piliin ang file mula sa computer niyo. (PNG, JPG, at WEBP formats ang tinatanggap).
Notes (Optional): Kung may gusto kayong idagdag na info tungkol sa ginawa niyo, i-type niyo lang sa box na ito.
Submit: I-click ang Submit button sa pinakababa para ma-save ang inyong progress.

Reminder!

Gawin ito bago mag-log out araw-araw. Importante ito para ma-track natin ang inyong compliance at hindi magka-issue sa commission niyo. Kung may technical problems kayo sa pag-upload, sabihan niyo agad ako.
